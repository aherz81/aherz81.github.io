12.03.02 - I uploaded an updated version of the Script IDE. Cleaned up a lot, added TexShader.dll to the SDK and created some nicer interface classes for the vm/scripts. TexShader exports 2 different interfaces, one for the 3d engine coder and one for the shader coder. The 3d interface allowes compfortable and fast loading/execution of scripted shaders. The shader script interface basically works by derivering a certain Material class from the prototype TexShader class. You overwrite the Load/Unload and Execute functions which are called by the 3d interface at load time once. Within the Execute function you can call any opengl function and desribe the different passes. he passes are compiled into display lists later for best peformance. See this for more informations about TexShader.

31.01.02 - I uploaded an updated version of the Script IDE. I fixed a bug in the VM which caused the step by step execution (using F10 key inside the IDE) to malfunction. Additionally I added support for callback functions. Now it is possible to install a script function as a callback for a native function like the SetTimer function. To do so you have to create an interface for the script function using CreateCallBackHandler func. Then you can simply pass the created interface to the native function. (The interface infact is a unique native code function which will call the script function)
