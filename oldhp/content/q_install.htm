Installation of Q

Q is an open end multy component system ought to be extended by user plugins.

To run basic Q

Download and extract qcore1.zip
Download and extract qserver51.zip
Run Q.exe in the dir you extracted q to after having edited 'init.cfg' to fit your requirements

To run a new plugin

Download and extract the plugin to your q directory
Read the plugin's describtion
Maybe you have to edit 'import.il' and ad an entry for your new plugin if the plugin does not come with his own 'import.il'

To create your own plugin

Download and extract qplugin3.zip to your q folder
Download and extract some other plugin with source to start from(maybe reference and netinit)
Read the Q Info page to get more info
