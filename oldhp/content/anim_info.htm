AnimED


AnimED is a tool which I created so that my artists in the ethos project would be able to create skellets for imported 3dmax objects and animate those...

I made that stuff up myself as most stuff I did in that time cause I hardly had access to the internet..after having finished it I found out that what I actually had created was already there..called keyframed skelletal animation..
Every vertex of the object belonged to exact one bone...so there was no weighting.. but it still was cool..

As it was based on the ethos engine it was running glide only.
Normally my tools are pretty ugly to use as most stuff is steered via shortcuts but that is acceptable as long I'm the only person to use that tool. This time I had to create a GUI my artists would like..dunno if I succeeded though.. and no..I didn't knew/liked MFC then..but this is years ago...
